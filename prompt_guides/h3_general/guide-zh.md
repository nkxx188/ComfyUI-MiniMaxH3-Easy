# MiniMax H3 中文通用提示词规则

这是完整的中文通用规则。输出正文使用中文，但 H3 的固定字段、引用标签、时间码、标记和段落结构必须保持协议规定的写法。

## 工作流程

1. 判断输入模式：T2VA、I2VA、FL2VA、L2VA 或 Ref2VA。
2. 判断内容主线：普通场景、对白表演、动作、广告或混合内容。不要把这些内容类型误当成不同的 H3 输出格式。
3. 确定是单段连续镜头，还是需要多个镜头或上下文分段。
4. 使用用户指定的时长；没有指定时，采用合理的短视频时长，不凭空延长复杂剧情。
5. 只有当一个生成段无法稳定承载完整事件时才拆分，并把切点放在动作完成、构图明显变化、地点变化、时间变化或主体变化处。

## 中文表达原则

- 用自然、清楚、具体的中文，不做英文逐句硬翻译。
- 先写主体和核心事件，再写环境、动作、镜头、声音和限制条件。
- 优先使用可观察的动作、位置、状态、表情、光线、材质和声音。
- 把“高级”“震撼”“唯美”“电影感”“很有氛围”等抽象词改写为可执行的画面和声音细节。
- 一个句子尽量只承担一个主要变化，避免把多个动作、镜头和情绪塞进同一句。
- 时间顺序要明确：当前状态 → 动作发生 → 环境或人物反应 → 动作结果。
- 只补充让画面能够生成的必要细节，不凭空增加主要人物、品牌、对白、剧情或参考素材。
- 用户已经明确的动作、对白、歌词、品牌名和画面文字必须保留，不要擅自改写。

## 固定协议

以下内容必须保持原样，不翻译、不改名、不重编号：

- `integrated_multimodal_description`、`overall_soundscape`、`non_diegetic_music`；
- `subject_definitions`、`summary`、`retention_analysis`、`detailed_description`；
- `<Picture N>`、`<Video N>`、`<Audio N>`、`<Subject N>`；
- `[Shot N]`、时间码、`<d>...</d>`、`<scenetrans>`、`<cutoff>`；
- `S1`、`S2` 等说话人编号；
- `---` 分隔符、`N/A`、`fully_preserved`、`partially_preserved`、`attribute_transfer`、`weak_reference`、`fully_copy`、`partially_copy`、`reference`。

字段名称和固定协议值使用英文，字段内部的自然语言描述使用中文。对白、歌词、品牌名、画面文字和用户明确指定的专有名词保持原语言。

## 主体、环境和连续性

- 在第一个镜头建立主体身份、外观、服装、位置、环境、关键道具、光线和整体风格。
- 后续镜头只重复当前动作或理解画面所必需的连续性锚点，不机械复制整段描述。
- 保持人物身份、发型、服装、道具数量、空间方向、光线方向、色彩、材质和时间状态稳定。
- 如果前一动作改变了物体或人物状态，后一镜头直接写出已经发生的结果，例如“星星已经握在右手中”，不要只写“继续之前的动作”。
- 不写无法执行的元话语，例如“和之前一样”“延续上个镜头”“保持前面的感觉”。需要连续性时，直接写出当前需要的具体状态。

## 动作和镜头

- 每个镜头围绕一个主要可见事件展开。
- 动作尽量写成“起始状态 → 方向和变化 → 接触或反应 → 结束状态”。
- 说明动作的方向、速度、身体重量、物体受力、环境互动和完成姿态。
- 镜头运动只有在改变构图或服务于动作时才添加，写清类型、方向、幅度和速度。
- 轻微视角变化优先使用推近、拉远、横移、摇镜、俯仰或跟拍；只有出现新信息、地点、时间或明确视角变化时才切镜。
- 不要同时安排过多人物、动作、镜头运动和状态变化。复杂内容应减少同时发生的动作，或在真实可见的边界处分段。
- 不把“紧张”“悲伤”“兴奋”当成画面结果，改写为眼神、姿势、呼吸、停顿、微表情和可见反应。

## 对白、声音和画面文字

- 第一次出现说话人时，明确人物身份、位置、声音特征、语气、节奏或口音，并分配稳定的 `(S1)`、`(S2)` 编号。
- 对白和歌词只放在 `<d>` 中，保留原文、原语言和必要标点；不要翻译、扩写或替换用户给出的句子。
- 说明说话人的视线、呼吸、停顿、表情和口型同步。离屏旁白要明确写出，并说明画面人物嘴唇保持闭合。
- 对白跨镜头时使用 `<scenetrans>`，并说明声音连续通过切镜；视频结束时被截断的对白使用 `<cutoff>`。
- 画面中的招牌、字幕、包装、界面或标语用双引号写出准确文字，同时说明位置、出现时机和消失时机。
- `overall_soundscape` 只概括整个视频中的环境声、动作声和非语言人声，不重复完整对白或音乐。
- `non_diegetic_music` 只写角色听不到的背景音乐，描述乐器、节奏、速度、音量变化和结束方式，不只写抽象情绪。
- 角色能听见的现场音乐、收音机、电视、手机播放或人物演奏属于画面内声音，应写进主描述。
- 没有声音时使用 `N/A`，但只有用户明确要求完全静音时才这样写。

## 参考素材

- 只使用用户提供或实际连接的媒体引用。
- 图片、视频和音频使用正确的 `<Picture N>`、`<Video N>`、`<Audio N>` 标签，不把文件名、上传顺序和内容角色混为一谈。
- 参考图片如果是首帧、尾帧或具体关键帧，要在对应时间和镜头中明确对齐；如果只提供人物、场景、服装、风格或动作信息，就作为相应主体的参考来源。
- 参考视频只有在被编辑、续接，或提供剪辑、节奏、镜头结构时才作为视频结构来源；视频中的人物、场景或动作仍需作为独立主体说明。
- 参考音频需要明确是完整复制、部分复制，还是只参考音色、节奏、歌词、对白或声音质感。
- 保持参考素材要求保留的身份、服装、道具、运动方向、光线、构图和连续性；忽略用户没有要求的水印、界面、压缩瑕疵、无关背景和原始姿势。
- 当模型没有实际读取媒体时，保留必要标签，但只能依据用户文字和明确指令推断，不能虚构媒体中的外观、动作、人物或声音。

## 稳定性和防错

- 不凭空添加字幕、Logo、水印、额外人物、额外物体或未提供的参考标签。
- 避免手指、脸部、服装、道具数量、物体位置、运动方向和光线在镜头间突然变化。
- 每个镜头要有明确的当前状态和动作终点，避免瞬移、动作跳步、人物穿模或物体无原因出现和消失。
- 动作密度、镜头速度和声音变化必须适合目标时长，不为了填满时长重复同一句描述。
- 用户要求的视觉风格必须贯穿全片，但不要擅自加入真人、二维动画、三维、Vlog 或广告风格。

## 输出要求

- 只返回最终可复制的 H3 提示词，不输出分析、解释、Markdown 围栏、标题或额外说明。
- 普通单段模式返回一个完整提示词。
- 基础模式使用 `integrated_multimodal_description`、`overall_soundscape`、`non_diegetic_music`。
- 完整参考模式使用 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description`、`overall_soundscape`、`non_diegetic_music`，顺序不能改变。
- 上下文分段模式由独立的上下文规则负责段数、`---` 分隔和跨段连续性；本通用规则负责中文表达、协议和稳定性。
