# 中文动作附加规则

本文件只在用户选择“动作”方案时加载。完整中文通用规则、基础模式规则或完整参考模式规则继续负责 H3 协议；本文件只强化身体动作、物体互动和镜头节奏。

## 核心重点

- 每个镜头优先安排一个主要动作事件，必要时再安排一个直接结果，不要同时塞入多个互不相关的动作。
- 每个动作都写清楚：起始状态、运动方向、施力方式、接触对象、环境反应和结束姿态。
- 动作用可观察的动词表达，不要只写“激烈”“流畅”“震撼”“高速”或“充满力量”。
- 明确人物或物体从哪里开始、向哪里移动、移动多远、何时接触，以及接触后发生什么。

## 动作链

优先按照下面的因果顺序组织动作：

```text
准备姿势 → 发力或启动 → 移动与接触 → 对象反应 → 动作完成姿态
```

例如不要只写“男人挥拳击倒敌人”，而要说明身体转向、拳头方向、接触位置、对方失去平衡的反应，以及男人最后停在哪里。

- 奔跑要写起步方向、步伐、身体重心、地面反应和停下方式。
- 拿取物体要写手从哪里伸出、如何接触、如何抓住以及物体最后的位置。
- 推、拉、摔、碰撞和破坏要写受力对象的变化、声音和碎片或液体的运动。
- 打斗要避免连续堆叠无法分辨的招式，每个镜头只保留主要攻击、闪避或反应。

## 镜头和节奏

- 镜头运动要跟随动作的方向和节奏，而不是无意义地快速摇晃。
- 用跟拍、横移、推近或拉远展示运动轨迹；用近景强调接触、撞击、手部操作和最终状态。
- 快速动作仍然要保留可理解的起点和终点，不能用“瞬间完成”替代过程。
- 动作镜头的切点优先放在动作完成、碰撞发生、主体改变方向、物体状态改变或结果稳定的位置。
- 如果首尾帧或参考视频限制了姿势，优先设计一条能够真实到达目标姿势的中间路径，不要瞬间跳到参考状态。

## 物理和连续性

- 保持人物重心、四肢数量、接触关系、服装、道具和运动方向稳定。
- 物体被拿起、放下、打开、打碎或移动后，后续镜头要直接写出新的状态。
- 动作必须符合环境和物体的重量、惯性、摩擦、碰撞和遮挡关系。
- 不让人物无原因瞬移、穿过物体、反向移动或在同一镜头中重复出现。

## 动作声音

- 关键动作配上对应的可听见声音，例如脚步、衣料摩擦、金属碰撞、木头断裂、落地、喘息或撞击。
- 声音的时间点要跟动作接触或结果同步，不要把所有声音堆在 `overall_soundscape` 中而忽略主描述中的同步关系。
- 背景音乐不能掩盖动作声；强烈动作可以有短暂的音乐停顿或动态变化。

## 动作防错

- 不在短时长中安排过多连续动作、多个主体和复杂镜头切换。
- 不用抽象形容词代替动作轨迹、身体重量和因果关系。
- 不擅自增加武器、敌人、爆炸、血液或破坏效果。
- 不把动作拆在不完整的中间状态；需要分段时，将切点放在一个动作或反应已经完成的位置。
