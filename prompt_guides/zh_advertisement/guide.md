# 中文广告附加规则

本文件只在用户选择“广告”方案时加载。完整中文通用规则、基础模式规则或完整参考模式规则仍然负责 H3 协议；本文件只增加产品展示和商业信息传达方面的引导。

## 核心重点

- 明确广告的主体是产品、服务、品牌或一个需要被记住的核心卖点。
- 每个镜头都要回答一个问题：观众此刻应该看清产品什么特征、功能、使用方式或品牌信息。
- 产品展示优先于无关的环境和人物表演，人物动作只能服务于产品使用和信息表达。
- 产品的外形、比例、颜色、材质、包装、Logo、按钮、接口和文字必须在镜头间保持一致。

## 商业镜头顺序

根据用户目标，优先组织成清晰的商业节奏：

```text
吸引注意 → 建立产品 → 展示使用或卖点 → 特写关键细节 → 品牌或产品收束
```

不要求每个广告都机械包含全部步骤。如果用户只要求产品特写或功能演示，就只保留真正需要的镜头。

- 开头用清楚的主体、动作或视觉变化吸引注意，但不要为了吸引注意遮挡产品。
- 产品首次出现时说明外观、位置、光线和画面层级。
- 展示功能时写明动作、输入、输出或可见结果，不用“强大”“高端”“极致”等抽象词替代效果。
- 关键细节使用近景或特写，并保持产品状态、方向和材质连续。
- 结尾可使用产品定格、包装展示、Logo 或明确的结束构图，但只有用户提供或要求的品牌文字才能出现。

## 产品和品牌一致性

- 不改变用户提供的品牌名、Logo、包装文字、型号、颜色和产品比例。
- 画面文字、产品标签和价格等信息必须逐字保留；不确定的文字不要编造。
- 不凭空添加竞品、功效、认证、销量、价格、口号或法律声明。
- 如果提供了产品参考图片或视频，要明确它是外观、材质、功能、包装还是镜头动作的来源。
- 如果人物使用产品，保持人物手部、产品接触位置和产品朝向合理，避免产品在镜头间变形或重复出现。

## 镜头、光线和声音

- 镜头运动应帮助观众看清产品，而不是抢走产品的注意力。
- 产品特写保持稳定构图、清楚轮廓和可识别的关键细节，避免过度景深、快速摇晃或强烈遮挡。
- 光线要服务于材质和功能展示，例如用侧光表现纹理，用高光表现表面，用柔光保持包装文字清晰。
- 动作声、开合声、按键声、倒液体声或产品运行声应与对应动作同步。
- 背景音乐保持节奏和品牌气质，但不要掩盖旁白、卖点或产品声音。

## 广告文字和对白

- 旁白或人物对白要明确说明谁在说、何时说、语气和口型。
- 用户提供的广告文案必须保留原文，不改写成新的宣传语。
- 屏幕文字要写清准确内容、位置、出现时间和消失时间；除非用户要求，不主动生成字幕或口号。
- 文字较多时优先减少无关画面动作，给文字足够的停留时间。

## 广告防错

- 不把广告自动写成剧情短片，不添加与产品无关的复杂人物关系和故事线。
- 不用大量风格形容词掩盖产品信息，不让镜头始终只拍环境而看不清产品。
- 不凭空修改产品、Logo、品牌文字或功能结果。
- 不同时展示过多卖点；优先保证一个核心卖点清楚、完整、可验证地出现。
